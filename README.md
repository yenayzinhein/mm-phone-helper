# ဖုန်းပြော အကူ — English call → ယဉ်ကျေးသော မြန်မာစာ

နေ့တိုင်း အင်္ဂလိပ်လို ဖုန်းလက်ခံဖြေဆိုရသူများအတွက်။
ဖုန်းထဲက အင်္ဂလိပ်စကားသံကို နားထောင်ပြီး **ယဉ်ကျေးသော မြန်မာစာ** ဖြင့်
ပြန်ဖြေရမည့်စာကို ချက်ချင်း ဖော်ပြပေးသည်။

```
🔊 အင်္ဂလိပ်အသံ  →  📝 အင်္ဂလိပ်စာ  →  🇲🇲 ယဉ်ကျေးသော မြန်မာစာ  →  📋 ကူးယူ/ဖတ်ပြ
```

## Web app လုပ်နည်း

```bash
cd mmpolite
pip install -r requirements.txt
python3 app/server.py            # http://localhost:5000
```

ပထမဆုံးအကြိမ်တွင် Whisper `tiny.en` (~75 MB) ကို `~/.cache/whisper` သို့
download လုပ်သည်။ ၂-core CPU ဖြင့် ၆ စက္ကန့်အသံကို **၀.၈ စက္ကန့်** အတွင်း ခွဲခြမ်းနိုင်သည်။

### Test

```bash
python3 -m pytest tests/ -q      # 93 passed
```

## ယဉ်ကျေးမှု စနစ် (politeness engine)

`app/politeness.py` သည် စက်ဘာသာပြန်၏ အမှားများကို ဖုန်းမပြောမီ ပြင်ပေးသည်။

**၁။ ကျား/မ အလိုက် အသုံးအနှုန်း**

| | ကျား | မ |
|---|---|---|
| ကိုယ် | ကျွန်တော် | ကျွန်မ |
| ဖက်ဘက် | ခင်ဗျာ | ရှင် |
| စာကြောင်းဆုံး | …ပါ ခင်ဗျာ။ | …ပါ ရှင်။ |

**၂။ ဘာသာပြန်အမှား ပြင်ခြင်း**

- `ကျွန်ုပ်` (စာရေးပုံစံ) → `ကျွန်တော်`/`ကျွန်မ` (ပြောပုံစံ)
- `သင်`/`သင့်` — ဘာသာပြန်က "your" ကို `သင်၏` ဟု ပြန်ရာတွင် ၎င်းသည်
  **မြန်မာနားထောင်သူ** ဖြစ်သည်။ `ခင်ဗျာ၏` ဟု မပြောင်းရ — ဒါက အဓိပ္ပာယ်ပြောင်းသွားမည်။
- MT ၏ space ပိုများ (`သင် ၏ အထုပ် ကို`) → ပြန်ဆက် (`သင်၏အထုပ်ကို`)
- `မင်း`/`နင်`/`ကောင်` → `ခင်ဗျာ`/`ရှင်`
- `…တယ်` → `…ပါတယ်`၊ `နော်`/`ကွ`/`ဗျ` ဖယ်ရှား

**၃။ ဦးတည်ရာ မှားခြင်းကို ကာကွယ်ခြင်း**

`"We will call you back"` (ဖက်ဘက် ပြန်ခေါ်မည်) နှင့် `"I'll call you back"`
(ကိုယ် ပြန်ခေါ်မည်) သည် အဖြေလုံးဝ ကွဲသည်။

```
We will call you back tomorrow. → ဟုတ်ကဲ့။ ပြန်လည် ဆက်သွယ်ပေးပါ ခင်ဗျာ။
I'll call you back tomorrow.    → ကျွန်တော် ပြန်လည် ဆက်သွယ်ပါမယ် ခင်ဗျာ။
```

**၄။ "This is Anna" သည် ဖက်ဘက်၏ အမည်**

Whisper သည် ဖက်ဘက်စကားကို ရေးသားသည်။ ထို့ကြောင့် `"This is Anna"` ကို
`"ကျွန်တော် Anna ဖြစ်ပါတယ်"` ဟု မပြောင်းရ။ `"ဟုတ်ကဲ့ ခင်ဗျာ။"` ဟုသာ ဖြေသည်။

## ဘာသာပြန် အဆင့်ဆင့်

1. **Phrasebook** (offline, ၃၁ ခု) — လက်ဖြင့် စစ်ဆေးထားသော စကားလုံးများ။ အရည်အသွေး အမြင့်ဆုံး။
2. **MyMemory MT** (online) → `to_polite()` ဖြင့် ယဉ်ကျေးအောင် ပြောင်းသည်။
3. **Glossary** (offline, စကားလုံး ~၈၀) — အင်တာနက် မရသည့်အခါ အကြမ်းဖျင်း။
4. **Fallback** — `"တစ်ဆိတ်လောက် ထပ်ပြောပေးပါ ခင်ဗျာ။"`

စာကြောင်းရှည်များကို စာကြောင်းခွဲပြီး **အဖြေ တစ်ခုစီ** ထုတ်ပေးသည်။

## API

| Endpoint | လုပ်ဆောင်ချက် |
|---|---|
| `GET /` | Web UI |
| `GET /api/health` | Model အခြေအနေ |
| `GET /api/phrasebook?gender=male\|female` | စကားလုံးစာအုပ် |
| `POST /api/translate?gender=…` `{text}` | အင်္ဂလိပ် → ယဉ်ကျေးမြန်မာ |
| `POST /api/polish?gender=…` `{text}` | မြန်မာ → ယဉ်ကျေးမြန်မာ |
| `POST /api/transcribe?gender=…` (multipart `audio`) | အသံ → စာ → အဖြေ |

အသံဖိုင်: `wav, webm, ogg, m4a, mp3, mp4, aac, flac` — အများဆုံး 25 MB။

## သိထားသင့်သည်များ

- **Whisper model** — `tiny.en` ကို သုံးသည်။ ဆူညံသံများသော လိုင်းတွင်
  အမှားရှိနိုင်သည်။ `stt.AVAILABLE` တွင် `base.en` ထည့်ပြီး `?model=base.en`
  ဖြင့် ခေါ်နိုင်သည် (ပိုနှေး၊ ပိုတိကျ)။
- **PyAV version** — `faster_whisper.audio.decode_audio` သည် PyAV ≥ 16 နှင့်
  မကိုက်ပါ (`metadata_errors` kwarg)။ ထို့ကြောင့် `app/stt.py` သည် PyAV ဖြင့်
  ကိုယ်တိုင် decode လုပ်ပြီး numpy array ကိုသာ ပေးသည်။
- **MT quota** — MyMemory သည် အခမဲ့ tier တွင် တစ်နေ့ စာလုံးအရေအတွက် ကန့်သတ်ရှိသည်။
  ကုန်လျှင် glossary သို့ အလိုအလျောက် ကျသွားသည် (crash မဖြစ်)။
- **Privacy** — အသံဖိုင်သည် ဆာဗာပေါ်တွင် temp file အဖြစ်သာ ရှိပြီး
  transcription ပြီးသည်နှင့် ချက်ချင်း ဖျက်သည်။
- **မှတ်တင်ခြင်း** — ဖုန်းခေါ်ဆိုသူ၏ ခွင့်ပြုချက်မပါဘဲ အသံမှတ်တင်ခြင်းကို
  ရှောင်ကြဉ်ပါ။ နိုင်ငံအလိုက် ဥပဒေ ကွဲပြားနိုင်သည်။
